# Notas de análisis

- Los porcentajes de cambio se calculan a partir de las medias grupales.
- El ANCOVA usa postest como desenlace, grupo como factor y pretest como covariable.
- La inferencia recomendada usa errores agrupados por `family_code`, porque cada código familiar contiene una persona experimental y una de control.
- Cohen dz describe el cambio intragrupal.
- Hedges g compara los cambios entre grupos.
- WHOQOL-BREF se presenta como módulo analítico independiente.
- La evaluación PLN usa etiquetas operativas y partición por familia; no sustituye un corpus gold etiquetado de manera independiente.
