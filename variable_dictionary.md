# 📘 neuroguIA Dataset — Variable Dictionary

This document describes the primary variables included in the **neuroguIA conversational dataset**, generated from the hybrid conversational AI system designed for socioemotional accompaniment in neurodivergent contexts.

---

# 🧠 General Dataset Information

| Variable | Description |
|---|---|
| family_id | Anonymous identifier for each family or support unit |
| profile_id | Anonymous identifier for participant profile |
| case_id | Unique identifier for each conversational case/session |
| session_scope_id | Identifier for conversational session grouping |
| created_at | Timestamp of record creation |
| updated_at | Timestamp of latest update |

---

# 💬 Conversational Variables

| Variable | Description |
|---|---|
| message_id | Unique identifier for each conversational message |
| speaker | Indicates message source (user/system) |
| turn_index | Sequential order of conversational turns |
| message_text | Conversational content text |
| message_length_chars | Character length of message |
| session_length | Number of turns/messages in session |
| conversation_type | General conversational context classification |

---

# 🧠 NLP & Semantic Processing Variables

| Variable | Description |
|---|---|
| detected_intent | Primary conversational intent detected by the NLP pipeline |
| detected_category | Functional or emotional conversational category |
| semantic_signal | Semantic similarity signal derived from embeddings |
| classic_ml_signal | Signal generated by classical ML classifier |
| confidence_score | Aggregated confidence score of classification pipeline |
| semantic_similarity | Semantic similarity metric between conversational patterns |
| embeddings_used | Indicates whether embeddings were applied during processing |
| fallback_triggered | Indicates if fallback conversational logic was activated |

---

# ⚙️ Functional & Emotional State Variables

| Variable | Description |
|---|---|
| primary_state | Main detected functional/emotional state |
| emotional_state | Emotional interpretation inferred from conversation |
| executive_dysfunction | Detection flag for executive dysfunction indicators |
| sensory_overload | Detection flag for sensory overload indicators |
| burnout_detected | Detection flag for caregiver/user burnout |
| shutdown_detected | Detection flag for shutdown-related patterns |
| meltdown_detected | Detection flag for meltdown-related patterns |
| emotional_saturation | Detection flag for emotional saturation indicators |

---

# 🧩 Adaptive Decision Variables

| Variable | Description |
|---|---|
| response_mode | Type of adaptive response strategy selected |
| routing_decision | Conversational routing result |
| intervention_type | Suggested adaptive support or microaction |
| adaptive_strategy | Strategy selected by the decision engine |
| microaction_generated | Indicates whether a microaction was generated |
| routine_generated | Indicates whether an adaptive routine was suggested |

---

# 🧠 Contextual Memory Variables

| Variable | Description |
|---|---|
| memory_reference_id | Identifier linking contextual memory records |
| contextual_memory_used | Indicates if contextual memory participated in response generation |
| memory_priority | Priority level assigned to memory retrieval |
| reusable_response | Indicates if response was stored for supervised reuse |
| curated_conversation | Indicates whether conversation was selected for curation |
| learned_pattern_id | Identifier for extracted conversational pattern |

---

# 🗄️ Database & Persistence Variables

| Variable | Description |
|---|---|
| backend_provider | Persistence backend used (SQLite/PostgreSQL/Supabase) |
| provider | AI provider used during generation |
| model_name | Model identifier used during conversational processing |
| schema_version | Database schema version |
| metadata_json | Serialized JSON metadata associated with conversation |
| json_payload | Additional serialized structured data |

---

# 📊 Longitudinal Analysis Variables

| Variable | Description |
|---|---|
| session_frequency | Number of sessions associated with participant/family |
| longitudinal_index | Sequential longitudinal interaction index |
| interaction_duration | Estimated interaction/session duration |
| engagement_level | Estimated engagement metric |
| followup_required | Indicates if follow-up interaction was recommended |

# 🔒 Privacy & Ethical Variables

| Variable | Description |
|---|---|
| anonymized | Indicates record anonymization status |
| pii_removed | Indicates personally identifiable information removal |
| research_use_only | Indicates academic/research-only usage |

# ⚖️ Ethical Notice

All variables and conversational structures included in this dataset were anonymized prior to publication.

The dataset was developed exclusively for:

- academic research
- educational purposes
- conversational AI experimentation
- Natural Language Processing (NLP) research

No personally identifiable information (PII) is included in the public dataset release.
